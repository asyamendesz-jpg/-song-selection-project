# Подборщик песен

Русскоязычный веб-квиз, который помогает выбрать учебный репертуар. Подбор идёт по правилам внутри приложения, без микрофона, регистрации и внешних платных API.

Опубликованный снимок этой версии: тег `2026-10-31-two-free-vocal-songs`. Сайт: https://asyamendesz-jpg.github.io/-song-selection-project/

## Что сейчас работает

- Квиз отбирает песни по возрасту текста, языку (точное совпадение), жанру, настроению и цели.
- Фильтры нот: любые; с вокальными нотами; только с бесплатными вокальными нотами.
- В карточке и в Word есть ссылки на ноты; бесплатные вокальные открываются кнопкой «Открыть бесплатные ноты» (для сборника — со страницей). Платные остаются «Купить ноты» / «Купить сборник с этой песней». Скачивания нот внутри приложения нет.
- Подборку можно скачать как Word. Кнопка старта квиза нажимается.

## Проверенные ограничения

- Диапазон, тональность, тесситура и сложность голоса в каталоге не выдуманы: пока `null` / `unverified`.
- Фортепианное соло без вокальной строки не считается нотами для пения и не открывает фильтры вокальных нот.
- Платный предпросмотр не помечается как бесплатный. Нечитаемый скан не показывается и не даёт права на фильтры вокальных нот.
- Новый бесплатный источник можно помечать визуально проверенным только после просмотра страниц этой песни (ноты, ключи, знаки, длительности, слова), а не после одного открытия PDF.

## Как запустить

Нужны Node.js 18+ и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

Сборка:

```bash
npm run build
npm run preview
```

Проверка логики подбора:

```bash
npm test
```

## Где заменить демонстрационный каталог

Файл `src/data/catalog.ts`.

Для каждой версии указывайте только проверенные значения. Если диапазон, тональность или тесситура не измерялись у конкретной аранжировки, оставляйте `null`. Не переносите характеристики одной записи на другую тональность или кавер.

Статус проверки:

- `unverified` — предварительный вариант;
- `rangeChecked` — диапазон проверен именно для указанной версии.

После замены каталога логику в `src/logic/matching.ts` менять не обязательно, если структура записи сохранена.
