# Подборщик песен

Русскоязычный веб-квиз, который помогает выбрать учебный репертуар. Подбор идёт по правилам внутри приложения, без микрофона, регистрации и внешних платных API.

## Как запустить

Нужны Node.js 18+ и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

Сборка:

```bash
npm run build
npm run preview
```

Проверка логики подбора:

```bash
npm test
```

## Где заменить демонстрационный каталог

Файл `src/data/catalog.ts`.

Для каждой версии указывайте только проверенные значения. Если диапазон, тональность или тесситура не измерялись у конкретной аранжировки, оставляйте `null`. Не переносите характеристики одной записи на другую тональность или кавер.

Статус проверки:

- `unverified` — предварительный вариант;
- `rangeChecked` — диапазон проверен именно для указанной версии.

После замены каталога логику в `src/logic/matching.ts` менять не обязательно, если структура записи сохранена.
